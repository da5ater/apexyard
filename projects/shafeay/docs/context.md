# Shafeay Context

## Origin

This project came from a product-shaping conversation about an agent-first learning companion for self-taught programmers, solo builders, solo creators, and knowledge workers.

The first wrong implementation attempt placed the runner inside ApexYard itself as `.claude/skills/self-development-lifecycle`. That was a product-boundary mistake. Shafeay is a separate project governed by ApexYard.

## Principles

- Knowledge graph first.
- Prerequisites and missing nodes are first-class.
- The graph expands when learner blind spots appear.
- Understanding happens through live node interviews.
- Preservation happens through local notes, artifacts, events, and gates.
- Artifacts are first-class citizens, especially code artifacts for programming topics.
- Obsidian/Markdown/HTML are the first surfaces.
- A polished GUI is deferred until the workflow proves valuable locally.

## First Sources

- Redux Toolkit course lectures combined into one bounded Markdown file.
- Later: UBC Systematic Program Design / How to Design Programs sections.

## First Real Slice

Take one source and one selected graph branch through the full local loop:

- source intake
- initial graph
- graph rendering
- branch selection
- node explanation
- open-ended diagnostic question
- pass/partial/fail scoring
- dynamic graph update
- per-node notes and artifacts
- event log

Do not shrink this to a toy one-node spike. The correct constraint is source size and one branch, not removing the real loop.
